# Customer_Dashboard
# 📊 Data Analytics Project

## 1. Project Overview

This project focuses on analyzing a dataset to extract meaningful insights and support data-driven decision-making.

The project follows an end-to-end data analytics workflow, starting with data loading and exploration in Python, followed by data cleaning, SQL analysis using MySQL, and interactive dashboard development in Power BI.

A detailed analytical report and presentation (PPT) are also created to communicate the key findings and business insights.

### Objectives
- Understand the dataset through Exploratory Data Analysis (EDA).
- Clean and preprocess data to ensure accuracy and consistency.
- Perform SQL queries to analyze important business metrics.
- Build an interactive Power BI dashboard.
- Generate a detailed analytical report and presentation.
- Identify trends, patterns, and actionable insights.

- Checked the number of rows and columns.

- Identified trends, patterns, and relationships.

- Removed duplicate records where necessary.

- Imported the cleaned dataset into MySQL.
- Executed SQL queries to analyze business metrics.
- Used filtering, aggregation, GROUP BY, ORDER BY, and JOIN operations where required.
- Identified important trends and performance indicators.

### Step 5: Power BI Dashboard

## 8. How to Run the Project

### Prerequisites
Make sure the following tools are installed:

- Python 3.x
- Jupyter Notebook
- MySQL Server and MySQL Workbench
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://priyabhanubp376-star/Customer_Dashboard
```

### Step 2: Navigate to the Project Directory

```bash
cd Data-Analytics-Project
```

### Step 3: Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Step 4: Run Python Analysis

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open `data_analysis.ipynb` and execute the cells to perform data loading, EDA, and data cleaning.

### Step 5: Run SQL Queries

- Open MySQL Workbench.
- Create a database.
- Import the cleaned dataset into a table.
- Open `analysis_queries.sql`.
- Execute the queries to perform SQL analysis.

### Step 6: Open the Power BI Dashboard

- Open Power BI Desktop.
- Load `dashboard.pbix`.
- Update the data source path if required.
- Refresh the data to view the dashboard.

### Step 7: View the Report and Presentation

Open the project report and PowerPoint presentation from their respective folders.
